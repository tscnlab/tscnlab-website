REVIEW DECISIONS

The following decisions were approved on 16 November 2026.

- The Team page still lists the four summer interns announced in July 2025:
  Erwin Obias, Bruno Bustos, Mithish Ravisankar Geetha and Tre Ridgway-Davis.
  The user accepted the current listing for now. Team membership and roles
  remain unchanged.
- The homepage uses the 2024 group photograph. It remains useful, but a
  newer approved photograph would make the page more current. The user
  accepted the existing photograph for now.
- The expired MLST autumn 2026 call is marked closed on the homepage and PhD
  programme page in the separate tscnlab/website-join repository. The original
  15 November 2026, 23:59 CET deadline was rechecked against TUM's official
  application page on 16 November. No future round was advertised as open.
- Individual collection URLs are generated for team members, but their
  source files mostly have no biography and the member layout is absent.
  The Team overview uses cards rather than these URLs. The unused
  _members/manuel-spitschan.md also contains template text. This should be
  resolved before promoting individual profile URLs. The user accepted this
  content gap for now; it remains unchanged.
- No public preregistration index was found in the repository. The page now
  provides a contact route; study-specific registration links can be added
  once the lab provides an authoritative list. The user accepted this content
  gap for now; no speculative index was added.

Historical news, publication claims, member roles and ongoing collaborations
were preserved unless a specific correction could be supported. This review
does not certify every historical external link or every person's current
affiliation.
